## 🚀 Technical Implementation

### Data Flow
```
utils/demoData.ts
    ↓
Dashboard.tsx (displayData based on isDemo)
    ↓
DemoModeIndicator.tsx (showSnapshot mode)
    ↓
BankingScreen.tsx (martinezAccounts vs defaultAccounts)
    ↓
ProgressScreen.tsx (martinezMissions vs genericMissions)
```

### State Management
- `isDemo` flag passed down from App.tsx
- Demo data imported from centralized `demoData.ts`
- Conditional rendering based on demo state
- No localStorage pollution (all in-memory)

### Performance
- Demo data is memoized
- No API calls in demo mode
- Instant transitions
- Pre-calculated values
